# ServiceMonitor

Консольное приложение для проверки доступности интернет-сервисов и мониторинга собственных сайтов.

## Назначение

Быстро проверять, какие сервисы доступны, а какие заблокированы или лежат: не по новостям, а по факту пинга. Дополнительно позволяет мониторить собственные сайты.

## Целевая аудитория

- Пользователи, которым нужно знать доступность сервисов (YouTube, Discord, Telegram и др.)
- Веб-мастера, которым нужен мониторинг собственных сайтов
- Разработчики, которым нужна быстрая проверка инфраструктуры

## Предметная область

Мониторинг доступности веб-сервисов: проверка HTTP-статусов, отображение результатов, управление списком отслеживаемых сервисов.

## Основные сущности

- **Сервис** (dict): название, URL-адрес для проверки, описание
- **Результат проверки**: статус (доступен/недоступен), код HTTP-ответа
- **Список сервисов** (list): хранится в памяти, загружается из JSON-файлов

## Основные функции

1. Проверка доступности всех сервисов
2. Проверка отдельного сервиса по выбору
3. Отображение списка сервисов (с сортировкой по названию)
4. Поиск сервиса по подстроке названия
5. Добавление нового сервиса
6. Удаление сервиса

## Структура проекта

```
service-monitor/
├── README.md              — документация проекта
├── .gitignore             — игнорируемые файлы
├── requirements.txt       — зависимости разработки
├── conftest.py            — конфигурация pytest
├── main.py                — точка запуска, меню, вывод данных
├── checker.py             — проверка сервисов, поиск, сортировка
├── storage.py             — загрузка и сохранение JSON
├── utils.py               — безопасный ввод
├── data/                  — JSON-файлы сервисов
│   ├── youtube.json
│   ├── discord.json
│   ├── telegram.json
│   ├── yandex.json
│   ├── gazprom.json
│   ├── apple.json
│   ├── google.json
│   └── fortnite.json
└── tests/                 — автоматизированные тесты
    ├── test_checker.py
    └── test_storage.py
```

Каждый сервис хранится отдельным JSON-файлом в папке `data/`, файл можно править или удалять вручную.

## Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск программы

```bash
python3 main.py
```

## Меню

```
1. Проверить все сервисы
2. Проверить сервис выборочно
3. Показать список сервисов
4. Найти сервис по названию
5. Добавить сервис
6. Удалить сервис
7. Выход
```
